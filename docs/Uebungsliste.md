# Alle Übungen der App

Stand 31.10.2026, direkt aus dem Code erzeugt: **780 Kraftübungen** und **114 Dehn-, Mobilitäts- und Faszienrollen-Übungen** – zusammen **894**.

Aufbau wie in der App: **Muskelgruppe → Zielmuskel**, darin nach Gerät sortiert. Die drei Kabel-Aufbauten sind eigene Geräte: **Kabelzug (einzeln)** = eine Rolle, **Kabelturm-Paar (Crossover)** = zwei gegenüberliegende Türme, **Doppelkabelzug (Functional Trainer)** = zwei Rollen nebeneinander an einem Gerät.

Legende: ★ = Startliste (nutzen die Vorlagen des Planassistenten) · ⏱ = wird in Sekunden gemessen · ↔ = einseitig, erst links, dann rechts.
Alle Anleitungen und Zuordnungen sind Vorschläge ohne Fachprüfung (Phase 10.1). Cardio (Laufband, Rad, Rudergerät …) folgt als eigener Schritt.
