# Übungsbilder: die 150 wichtigsten Übungen (Zulieferung für Higgsfield)

Stand 02.11.2026. Reihenfolge = Reihenfolge der Bilderstellung. Ermittelt aus dem Code, nicht nach Gefühl:
1. alle Übungen aus Lucs Trainingsplan (`lucs-training.myhealth.json`),
2. Übungen aus den fünf Programm-Vorlagen (je Vorkommen höher),
3. danach der Katalog: Grundübungen (Kniebeuge, Hüftbeuge, Drücken, Ziehen, Ausfallschritt) und Anfängerstufe zuerst,
   häufige Geräte (Lang-/Kurzhantel, Maschine, Körpergewicht) vor seltenen,
4. höchstens 18 je Muskelgruppe aus dem Katalog, damit alle Bereiche vorkommen.
